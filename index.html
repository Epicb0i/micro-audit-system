MICRO-AUDIT SYSTEM

Detailed Project Explanation ΓÇö Divided for 3 Persons

Project Overview

The Micro-Audit System is a full-stack Java web application designed to bring process accountability and transparency to college committees. It tracks committee actions (approval requests, purchase sanctions, event budgets, etc.), records every operation in an immutable audit trail, detects delay patterns using analytics, and provides role-based dashboards for three roles: Member, Committee Head, and System Auditor.

Experiment 2 ΓÇö JavaScript Classes + JSON

JavaScript Classes Created

1. User class (js/User.js)

  • Properties: id, role, name, department, email, phone, committee, loginTime, sessionId
  • Methods:
    • toJSON() ΓÇö converts user object to JSON string using JSON.stringify()
    • static fromSession() ΓÇö reconstructs User from sessionStorage (deserializes JSON)
  • Concept: ES6 classes, constructors, static methods, sessionStorage API, JSON serialization/deserialization.
class User {
  constructor(id, role) {
    this.id = id;
    this.role = role;
    this.name = id;
    this.department = '';
    this.email = '';
    this.phone = '';
    this.committee = '';
    this.loginTime = new Date().toISOString();
    this.sessionId = 'SES_' + Math.random().toString(36).substr(2, 9).toUpperCase();
  }

  toJSON() {
    return JSON.stringify({
      id: this.id, role: this.role, name: this.name,
      department: this.department, email: this.email, phone: this.phone,
      committee: this.committee, loginTime: this.loginTime, sessionId: this.sessionId
    });
  }

  static fromSession() {
    const raw = sessionStorage.getItem('currentUser');
    if (!raw) return null;
    const data = JSON.parse(raw);
    const u = new User(data.id, data.role);
    u.name = data.name || data.id;
    u.department = data.department || '';
    u.email = data.email || '';
    u.phone = data.phone || '';
    u.committee = data.committee || '';
    u.loginTime = data.loginTime;
    u.sessionId = data.sessionId;
    return u;
  }
}

2. Action class (js/Action.js)

  • Properties: id, title, committee, status, createdAt, expectedClose
  • Methods:
    • getDelayHours() ΓÇö computes hours between now and expected close date (arithmetic on Date objects)
    • isDelayed() ΓÇö returns boolean
    • toJSON() ΓÇö serializes to JSON including computed delayHours
  • Concept: Date arithmetic, Math.max(), Math.floor(), JSON conversion, method chaining.
class Action {
  constructor(id, title, committee, status, createdAt, expectedClose) {
    this.id = id;
    this.title = title;
    this.committee = committee;
    this.status = status;
    this.createdAt = new Date(createdAt);
    this.expectedClose = new Date(expectedClose);
  }

  getDelayHours() {
    if (this.status === 'Approved' || this.status === 'Closed') return 0;
    const now = new Date();
    const diff = now - this.expectedClose;
    return Math.max(0, Math.floor(diff / 3600000));
  }

  isDelayed() { return this.getDelayHours() > 0; }

  toJSON() {
    return JSON.stringify({
      id: this.id, title: this.title, committee: this.committee,
      status: this.status, createdAt: this.createdAt,
      expectedClose: this.expectedClose, delayHours: this.getDelayHours()
    });
  }
}

3. ActionRequest class (js/ActionRequest.js)

  • Properties: id (auto-generated with Date.now()), title, type, committee, dueDate, description, priority, cost, approver, status, createdAt
  • Methods:
    • toJSON() ΓÇö JSON serialization
    • async submitToServlet() ΓÇö sends FormData to backend via fetch() POST
  • Concept: async/await, Fetch API, FormData, REST communication.
class ActionRequest {
  constructor(title, type, committee, dueDate, description, priority, cost, approver) {
    this.id          = 'ACT-' + Date.now();
    this.title       = title;
    this.type        = type;
    this.committee   = committee;
    this.dueDate     = dueDate;
    this.description = description;
    this.priority    = priority;
    this.cost        = cost;
    this.approver    = approver;
    this.status      = 'Created';
    this.createdAt   = new Date().toISOString();
  }

  toJSON() { return JSON.stringify(this); }

  async submitToServlet() {
    const formData = new FormData();
    Object.entries(this).forEach(([key, val]) => formData.append(key, val));
    const response = await fetch('../ActionServlet', { method: 'POST', body: formData });
    return response;
  }
}

Where in Project: DelayDetectionEngine.java and StreamsAnalytics.java

Although the project doesn't have a standalone Operation interface, the functional programming concept is extensively used through Java's built-in functional interfaces:

Lambda expressions used throughout the analytics layer:

// In DelayDetectionEngine.java ΓÇö Filter (Predicate<T> functional interface)
actions.stream()
    .filter(Action::isDelayed)                    // Predicate<Action> lambda
    .sorted(Comparator.comparingLong(Action::getDelayHours).reversed())  // Comparator lambda
    .limit(n)
    .collect(Collectors.toList());

// Grouping with lambda ΓÇö Function<T,R> functional interface
actions.stream()
    .collect(Collectors.groupingBy(
        Action::getCommitteeName,                 // Function<Action, String> (method reference = lambda)
        Collectors.averagingDouble(Action::getDelayPercentage)  // ToDoubleFunction<Action>
    ));

// forEach with lambda ΓÇö Consumer<T> functional interface
avgDelays.forEach((member, avgDelay) -> {
    double score = Math.max(0, Math.min(100, 100.0 - avgDelay));    // compute: subtraction
    scores.put(member, Math.round(score * 10.0) / 10.0);           // compute: multiplication, division
});

Experiment 5 ΓÇö PreparedStatement for Secure Parameterized Queries

Where in Project: Every DAO class uses PreparedStatement

The project exclusively uses PreparedStatement (never raw Statement) to prevent SQL injection:

// From UserDAO.authenticateJDBC() ΓÇö parameterized login
PreparedStatement ps = conn.prepareStatement(
    "SELECT u.*, c.name AS committee_name FROM users u " +
    "LEFT JOIN committees c ON u.committee_id = c.id " +
    "WHERE u.staff_id = ? AND u.password = ?");
ps.setString(1, staffId);    // Parameterized ΓÇö prevents SQL injection
ps.setString(2, password);   // Parameterized ΓÇö prevents SQL injection
// From AuditLogDAO.insertLogJDBC() ΓÇö nullable parameters
if (actionId != null) ps.setInt(1, actionId);
else ps.setNull(1, Types.INTEGER);  // Proper null handling

Try-with-resources is used everywhere: try (Connection conn = DBUtil.getConnection(); PreparedStatement ps = ...) ΓÇö ensures automatic resource closure.

Servlet Filter (AuditFilter.java)

The AuditFilter is a powerful concept that:

  1. Intercepts every HTTP request (<url-pattern>/*</url-pattern>)
  2. Extracts user info from session (userId, role, sessionId)
  3. Skips static resources (.css, .js, .png)
  4. Chains the request forward: chain.doFilter(request, response)
  5. Measures processing time: System.currentTimeMillis() before and after
  6. Logs to the audit trail database via AuditLogDAO

This is registered in web.xml:

<filter>
    <filter-name>AuditFilter</filter-name>
    <filter-class>com.microaudit.util.AuditFilter</filter-class>
</filter>
<filter-mapping>
    <filter-name>AuditFilter</filter-name>
    <url-pattern>/*</url-pattern>
</filter-mapping>

public void saveHibernate(Action action) {
    Transaction tx = null;
    try (Session session = HibernateUtil.getSessionFactory().openSession()) {
        tx = session.beginTransaction();
        session.persist(action);       // INSERT
        tx.commit();

    }
}

WebAppInitializer.java registers Spring's DispatcherServlet:

public class WebAppInitializer implements WebApplicationInitializer {
    @Override
    public void onStartup(ServletContext servletContext) {
        AnnotationConfigWebApplicationContext ctx = new AnnotationConfigWebApplicationContext();
        ctx.register(WebConfig.class);

        DispatcherServlet dispatcher = new DispatcherServlet(ctx);
        ServletRegistration.Dynamic registration = servletContext.addServlet("dispatcher", dispatcher);
        registration.setLoadOnStartup(1);
        registration.addMapping("/app/*");   // All /app/* requests go through Spring MVC
    }
}
